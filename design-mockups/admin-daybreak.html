Admin Portal

The staff side of the same room. Owners run the morning from a phone behind the bar — so the customer app’s Morning Mist gradient, frosted glass, and Marcellus-over-Jost voice stay, while the layout tightens: more numbers per card, the next action always one tap, and a single warm attention note for new orders instead of an alarm.

How admin differs from the customer app

Same brand, staff tempo. Identical gradient, glass cards, type pairing, and the one sage accent. What changes is density and intent: metadata steps down a half size, row gaps tighten from 12 to 8, and counts ride every filter chip so the queue can be read at arm’s length.

Action-first cards. Every order card ends in exactly one solid sage verb — Start Preparing, Mark Ready, Complete Order — mirroring the new → preparing → ready → completed workflow in the code. Cancel and delete are quiet ink-outlined ghosts behind a confirm, never red.

One status language, no rainbow. New = dawn pill, in progress = sage outline, ready = solid sage, completed = muted ink. Totals and stat figures are set in Marcellus so even the numbers speak the brand. Reviews, analytics, and settings follow the same kit: gold stars stay rating-only, charts are sage bars on glass, hours and notification toggles sit on hairline-ruled rows.

New tokens · attention without alarm
